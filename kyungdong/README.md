# 🏢 경동 공식 웹사이트 메인 페이지 클론코딩

HTML, CSS, JavaScript를 활용해 경동 공식 웹사이트의 메인 페이지를 정교하게 구현한 퍼블리싱 포트폴리오 프로젝트입니다. 웹 페이지의 구조를 직접 분석하고, 메인 비주얼 영역의 동적인 스와이프 인터랙션을 구현하는 데 중점을 두었습니다.

- **원본 사이트:** [경동 공식 홈페이지](http://www.kyungdong.co.kr/)
- **작업 유형:** 웹사이트 클론코딩 (개인 프로젝트)
- **제작 목적:** 취업 포트폴리오 구축 및 퍼블리싱 역량 향상

---

## ✨ 주요 기능 및 특징

### 1. 메인 비주얼 슬라이드 (Swipe / Slide)

- 메인 영역에 스와이프(Swipe) 터치/드래그 기능 적용
- 이전/다음 슬라이드 네비게이션 전환 기능 구현
- 사용자 인터랙션에 따라 텍스트와 콘텐츠가 자연스럽게 매칭되도록 화면 처리

### 2. 구조적 마크업 및 레이아웃

- `Header`, `Visual`, `Contents`, `Footer` 영역의 명확한 구조화
- 원본 사이트의 전체적인 레이아웃과 아이덴티티를 참고하여 정밀한 화면 배치
- 이미지, 텍스트, 버튼 요소의 디테일한 여백 및 스타일링 반영
